Web Design - Projects 2 and 3

For Projects 2 and 3, I developed interactive learning activities focused on generative AI literacy. These projects allowed me to explore HTML, CSS, and JavaScript while comparing traditional coding with AI-assisted development.

Project 2: Generative AI Literacy Quiz

I created an interactive multiple-choice quiz to help students assess their understanding of generative AI literacy. This project introduced me to designing and developing web-based assessments using HTML, CSS, and JavaScript.

View Quiz

Project 3: Traditional Drag-and-Drop Assessment

I developed a drag-and-drop sorting activity using traditional coding techniques. Students evaluate scenarios involving generative AI and sort them into categories based on appropriate use, the need for verification, or inappropriate use.

View Traditional Version

Project 3: AI-Assisted Drag-and-Drop Assessment

I created a second version of the drag-and-drop assessment using generative AI to develop and revise the HTML, CSS, and JavaScript. This allowed me to compare traditional coding with AI-assisted development while exploring different approaches to interactive instructional design.
